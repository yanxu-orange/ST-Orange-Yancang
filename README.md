# 砚藏

![砚藏横幅](assets/yanzang-release-banner.png)

砚藏是一款面向 Android 的 SillyTavern 个人资源管理器，用于保存与管理角色卡、世界书、预设、快速回复和聊天记录。

## 下载

[下载砚藏最新版本](https://github.com/yanxu-orange/yancang/releases/latest)

## 主要能力

- 集中整理五类 SillyTavern 资源
- 角色卡、世界书、预设与快速回复的导入、查看、编辑和导出
- 聊天记录归档、逐楼阅读、正则净化与阅读外观
- 直接 URL 导入及本地 SillyTavern 联动
- 完整备份与替换恢复

## 使用边界

本项目仅供个人非商业使用，请勿二次分发或用于商业用途。

请勿使用砚藏保存、转换或传播付费购得、倒卖而来，或来自商业化平台的资源，包括将此类内容转换为 SillyTavern 格式后再行保存。

请尊重每一份创作及其原有的使用边界。愿你珍惜所爱，也祝你天天开心。

完整说明见 [使用边界](USAGE_BOUNDARIES.md)。

## 安装与更新

1. 从 Releases 下载 APK。
2. 在 Android 系统中允许当前文件来源安装应用。
3. 安装更新前，建议先在砚藏的“设置 → 数据管理”中导出完整备份。
4. 只有 applicationId 与签名证书一致的正式版本才能直接覆盖安装并保留应用数据；每次 Release 会明确标注这两项信息。
