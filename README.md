# 砚藏

![砚藏横幅](assets/yanzang-release-banner.png)

把故事与角色，好好收藏。

砚藏是一款面向 Android 的 SillyTavern 个人资源管理器，用于保存与管理角色卡、世界书、预设、快速回复和聊天记录，也可整理画师串图片与提示词。

[下载砚藏PC版本](https://github.com/yanxu-orange/ST-Orange-Yancang-PC/releases/latest)

## 主要能力

- 集中整理角色卡、世界书、聊天补全预设、快速回复、聊天记录及独立画师串库
- 本地SillyTavern多选拉取角色卡、独立世界书、聊天补全预设与单角色聊天；角色卡可同时导入酒馆标签
- 角色版本内容摘要、原文件名与缩略图，版本头像独立绑定，PNG导入自动关联卡面
- 世界书发送至本地酒馆，同名明确覆盖或改名；角色卡内多套世界书，随卡导出和发送当前方案
- 预设多选分轮导入工作台，可加入已有/新建组或分别独立导入
- 开场白HTML/CSS阅读，共用聊天阅读设置
- 大文件聊天低内存导入、按楼阅读与下一楼预备，单楼修改不重写整份聊天文件
- 原始JSONL、砚藏编辑副本JSONL、阅读模式TXT和阅读模式HTML四类导出，原件保留
- 角色卡正则、聊天全局正则及聊天局部正则的单条JSON导出
- 五库导入预览统一层级与间距，六库导航与各库目录独立滚动
- 无脚本状态栏与受控HTML/CSS美化；远程图片默认关闭，可在阅读设置开启
- 官方TauriTavern同机单卡双向联动、Git桥安装说明和安全诊断手动导出
- 完整备份与替换恢复、附加资料收纳、文件夹/文件视图及可关闭的GitHub版本提醒
- 画师串图片与提示词整理、原图/示例图导出、封面管理及图片直链导入

## TauriTavern 联动

在官方TT扩展Git安装入口安装[砚藏联动](https://github.com/yanxu-orange/ST-Orange-Yancang-TT-Bridge)，具体步骤见砚藏设置内“使用说明”。已有ZIP桥时须避免两份同名桥同时启用，不删除角色资料。

连接每次最多十分钟，不自动重连或重放。首次初始化红警和手机后台暂失仍可能发生；部分未编辑回件仍可能判为另一个版本，保留预览选择。遇到持续问题，可从双端导出最近安全诊断，手动反馈；诊断不自动上传。

## 安装与更新

1. 从 Releases 下载 APK。
2. 在 Android 系统中允许当前文件来源安装应用。
3. 安装更新前，建议先在砚藏的“设置 → 数据管理”中导出完整备份。
4. 只有包名与签名证书一致的正式版本才能直接覆盖安装并保留应用数据；请使用本仓库 Releases 提供的 APK。
